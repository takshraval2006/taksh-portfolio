# Taksh Raval Portfolio

A responsive personal portfolio website for Taksh Raval, a Computer Science & Engineering student at Indus University.

## Files
- `index.html` — website structure/content
- `style.css` — custom responsive styling
- `script.js` — interactions and animations

## Run locally
Open `index.html` in a browser.

## Before publishing
Replace these placeholders in `index.html`:
- `your-email@example.com`
- GitHub `href="#"` with your real GitHub profile
- LinkedIn `href="#"` with your real LinkedIn profile
- Add real project repository/demo links

## GitHub
```bash
git init
git add .
git commit -m "Create Taksh Raval portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/taksh-raval-portfolio.git
git push -u origin main
```

## Vercel
1. Go to https://vercel.com/
2. Sign in with GitHub.
3. Click "Add New..." → "Project".
4. Import `taksh-raval-portfolio`.
5. Framework Preset: Other.
6. Click Deploy.
7. Vercel will provide your live URL.
